# SEO Content Plan

## Goal

Build an English-first content cluster around Morse code learning, practice methods, and amateur radio use so the site can grow search traffic and support future AdSense review.

## Priority 1: High-intent beginner pages

1. What is Morse code and why do people still learn it?
2. How to learn Morse code from zero
3. Best Morse code chart for beginners
4. Common Morse code mistakes beginners make
5. Koch method vs Farnsworth method
6. How long does it take to learn Morse code?
7. How to practice Morse code listening every day
8. How to improve Morse code WPM without losing accuracy

## Priority 2: Practice and retention pages

9. Best daily Morse code practice routine
10. How to stop counting dots and dashes
11. Morse code copying practice guide
12. How to review Morse code mistakes effectively
13. Why your Morse code speed stops improving
14. How to train Morse code on mobile and desktop
15. Best Morse code drills for rhythm recognition
16. How to build a 30-day Morse code study plan

## Priority 3: Amateur radio and advanced topic pages

17. Morse code terms every ham radio beginner should know
18. Q-codes explained for Morse learners
19. How Morse code is used in amateur radio today
20. Best Morse code practice path before your first QSO

## Page template suggestion

- One clear search intent per page
- One main H1 title
- Short intro that answers the query directly
- 3 to 5 practical sections with examples
- Internal links to training pages and related guides
- One short CTA back to the trainer or tutorial catalog

## Internal linking suggestion

- Link beginner pages to `index.html` and `tutorials.html`
- Link every practice article to at least 2 related tutorials
- Link amateur radio pages to abbreviation and Q-code guides
- Add a short related reading block at the end of each tutorial

## Publishing rhythm

- Publish 2 to 3 improved pages per week
- Refresh weak pages after Search Console data appears
- Improve pages with impressions but low click-through rate first
- Keep expanding only after the first cluster starts ranking

About Morse Trainer

Morse Trainer is a browser-based learning site for people who want to build Morse code skill through guided practice, structured study plans, and searchable tutorial content.

What this site does

The project combines interactive training tools with long-form tutorial pages so learners can both practice Morse code and understand the methods behind that practice.

Who it is for

This site is designed for beginners, self-learners, amateur radio users, and anyone who wants a more systematic way to improve listening, copying, pacing, and long-term retention.

Core product features

Current features include training levels, flashcards, listening drills, typing practice, Koch-style progression, study plans, progress statistics, account sync, and a points leaderboard.

Why tutorials matter here

The tutorial library helps learners move beyond one-off drills. It also gives the site a stronger public knowledge layer for search, sharing, and long-term content growth.

Current public site

The main site runs at https://www.mmccode.com. The API service currently runs at https://api.mmccode.com.

Roadmap

Next steps include improving tutorial quality, expanding the content library, refining mobile usability, adding more learning support pages, and preparing the site for stable search and ad traffic.

Routes for first-time learners, returning users, and site reviewers

First-time learners should usually begin with Start Here, then move to Learning Roadmap, and only after that branch into the broader tutorial catalog. Returning users who already know the basic flow can jump directly into Practice Guides Hub, the Tutorial Catalog, or the homepage training interface.

Site reviewers, partners, or anyone trying to judge whether the project is complete should read the public trust layer as well: About, Help Center, FAQ, Privacy Policy, Terms of Use, Advertising Disclosure, and Editorial Policy. Those pages explain how the public site is maintained beyond the interactive trainer itself.

If a page looks thin or outdated, where to go next

If a page feels incomplete, start by checking whether a stronger hub already covers the same topic. The tutorial catalog, history hub, practice-guides hub, glossary, help center, and site map are designed to reduce dead ends by grouping related material into clearer public routes.

If the issue is a factual error, a broken link, or wording that no longer matches the product, use the Contact page to report it. That correction flow matters for learner trust and also for public review, because a maintained site should make it easy to see where outdated information can be fixed.
